TOOL-PATH OPTIMIZATION IN FFF 3D PRINTING MACHINE
USING LINES APPROACH ALGORITHMS

Ahmed MERZAHa, Fatih V. CELEBI*

a Ankara Yildirim Beyazit University, Graduate School of Natural Sciences, Department of Computer
Engineering, TURKEY

*Corresponding Author: fatihvcelebi@gmail.com

Abstract
By using Fused Filament Fabrication (FFF) 3D Printing Machines we can create simple to complicate
objects by printing successive thin layers. The printing tool formed each layer by moving on a selected
path. According to the fact that there are a huge number of layers to print, the selection of path
determines the overall time needed for producing an object. Therefore, reducing the length of paths
becomes an essential part of the printing process. In this paper, we presented different algorithms to
optimize each layer, they are LinearGreedy and LinearTwoOpt, by covert each layer into lines to find
the optimal path. Hybrid algorithms are also presented by selecting an initial solution with a fast
algorithm (LinearGreedy), and after that, try to improve it by further exploration of the solution space
with the other algorithm (LinearTwoOpt). We concluded that the proposed hybrid algorithm seems to
be promising based on the obtained results.
Keywords: 3D Printing. Algorithm. Tool-Path Optimization. LinearGreedy. LinearTwoOpt. Traveling
Salesman Problem.
1. INTRODUCTION
Nowadays, the 3D printer can be manufactured at affordable prices and can be used as easy as an
office printer. The recent advances in 3D printing technologies make it compact enough to be one of
the office equipment. The 3D printer is often used for rapid prototyping. This process allows for
creating a solid object without any specific tooling. The creation of very complex objects in a short
time is one of the most significant advantages of this process. There are different 3D printing
technologies which can be used in this process, Stereo-lithography (SL), Selective laser sintering
(SLS), and Fused Filament Fabrication (FFF) [1].
In FFF 3D printing technology, the object is created by the deposition of the model material. This
process can be divided into four different tasks [2]: (i) Object Orientation: determine the best
orientation of the object. (ii) Support Generation: generate the additional element to hold the parts of
the object which will be removed after completion. (iii) Slicing: extracting the layers from the object
by using a special algorithm. (iv) Path Planning: use an algorithm to plan the path of the extruder to
move on.
To start the steps of building a prototype, we first design the real-life object as a surface model and
store it as an STL file [3]. After that, we sliced it into very thin layers. According to the orientation of
the object we already were chosen, the layers will be seen as a horizontal cross-section of the object.
Then, we will use the algorithms to generate the optimal path for each layer. We have to save the
generated path into a G-code file which will guide printing tool-path along the generated path [4].
In this paper, we concern the problem of finding the path to be generated for the 3D printer purposes.
The paths can be divided into two types: the contour paths and the raster paths. The 3D printer must
first print the contour paths. The raster paths are filling the interior section of the layer. The raster
paths take too much time to print and have to be optimized. We can consider this problem as a special
case of travelling salesman problem. Algorithms called LinearGreedy and LinearTwoOpt are proposed
in this paper for solving path planning problem. Hybrid algorithms from these two algorithms are also

2. RELATED WORKS
In [5], the authors improved the speed of the printing process by inspecting 3D printer trajectory
planning. They claimed that the printing speed mainly depends on the motion speed and path of the
printing nozzle. They decrease the transition time between print segments by using triangular and
trapezoidal velocity profiles. In their work, they modified several algorithms to adapt to the new
problem that was originally proposed as solutions for conventional travelling salesman problem. The
proposed changes are planned to get time-efficient trajectories for the nozzle of the printer. The
authors in [6] proposed a 3D printing path optimizer based on Christofides algorithm. Their testing
results on the proposed optimizer show decrease in the length of the motion paths compared to the
original optimizer used with the 3D printers. In [7], the authors present a proposal to reduce the length
of head repositioning path without material deposition in the path planning of FD processes. They
computationally tested two models, a simple greedy option (closest neighbour approach) and the other
model is a combination of closest and farthest insertion approach. Their results show a considerable
reduction in the repositioning distance by using these methods.  Furthermore, they observed that the
geometry of the part that is analyzed is affecting the results of each method. The authors of [8]
implemented algorithms for solving the path optimization problem. They used a designed two-stage
experimentation system to investigate the properties of the implemented MZZ-GA algorithm. They
had concluded that the proposed approach seems to be promising based on the obtained results. In [9],
the authors first introduced a genetic algorithm (GA) based approach to solve the significant wasted
time problem in the movement between the endpoint of one curve to the start vertex of the next one
along which a tool-path must work. After that, they presented a new approach using a hybrid approach
of Asymmetric Traveling Salesman Problem and Assignment Problem (TSP-Assign) to solve this
problem. Then, they developed an improved genetic algorithm based on the advantages and
disadvantages of these methods. Last, they compared the performance of the different techniques
regarding the real-time planning in layered manufacturing applications. The authors in [10] presented
two hybrid algorithms to reduce the total length of printing paths; they are Greedy Two Opt and
Greedy Annealing. They put an assumption for both algorithms that it is profitable to choose the first
solution from the faster algorithm and after that, trying to improve that solution using the slower
algorithm.

4. TSP AND TOOLPATH
We could consider the finding of the best path for the printing head of the 3D printer as a special case
of travelling salesman problem. There are some differences between the two problems like the tool-
path do not have to return to the starting point like in the travelling salesman. There are reported a
significant number of algorithms that used to solve the TSP.
4.1. Traveling Salesman Problem
If we have several cities and we have the exact distance between each two of these cities, the travelling
salesman problem is to find the shortest way to reach all the cities and return to the starting city so that
the cost of the travel between the cities is minimum [11].
In the 18th century, two mathematicians tried to put an algorithm to find the best solution for the
travelling salesman problem, they ware W. Hamilton and T. Kirkman [12].
4.2. Approximate Approaches for TSP
To solve the travelling salesman problem in an optimal way, we can use one of these methods: the
exact method and Held-Karp method. Branch and Bound is one of the exact methods. Branch and
Bound method is an algorithm design paradigm used to solve problems like mathematical, discrete,
and combinatorial optimization. This algorithm contains a systematic enumeration of candidate
solutions by the use of state space search. The other method is to find the lower bound of the Held-
Karp algorithm. By finding the lower bound of Held-Karp we will find the lower bound of the optimal
solution for the travelling salesman problem. We can evaluate the activity of any algorithm proposed
to solve the travelling salesman problem by using the lower bound of the Held-Karp algorithm.
The travelling salesman problem takes a huge computational time even there is not a huge number of
cities to find the optimal solution. So that we have to use the approximate algorithms to find a near-
optimal solution. The near-optimal solution we will get will take a reasonable computational time.
4.3. Path Construction
These algorithms will break when an answer is gotten and never goes to progress it. These algorithms
get a result in 10-15% of the ideal result.
Greedy is one of tour construction algorithms. In this algorithm, the next city will be selected
depending on the distance to it. The algorithm searches the distances to all the cities and select the
shortest one and add it to the path. the algorithm continues adding the cities as long as there are more
cites to add. No city will be adding more than one time.

4.4. Path Improvement
After generating the tour using any tour construction heuristic, an improvement heuristic can be
further applied to improve the quality of the trip formed. Commonly, the two opt and the three opt
exchange heuristic are applied for enhancing the solution. The act the two opt and the three opt
heuristic mostly depends on the path generated by the tour construction algorithm. Other methods of
improving the solution are to apply meta-heuristic approaches such as tabu search or simulated
annealing using the two opt and the three opt.
The 2-opt algorithm exchanges arbitrarily two ends from the previously produced route and rejoins the
new two routes produced. This is mentioned as a 2-opt switch. The rejoining is completed in such a
method to maintain the trip existed. It is only completed if the founded tour is smaller than the
original. It is continued until no further improvement is available. The resulting tour is now two
optimal. The three opt algorithm act in a similar way, but instead of changing the two edges it
changing three edges. This means there are two methods of reconnecting the three routes into a valid
tour. Search is finished when no more 3-opt swaps can improve the tour distance. If a route is three
optima, it is also two optimum. Processing the 2-opt change frequently outcomes in a route with a
distance fewer than 5% above the Held-Karp bound. The enhancement of a three opt move usually
creates a route about 3% more than the Held-Karp bound [12].
5. PROPOSED ALGORITHMS
We presented in this paper three different algorithms to find the minimum path. They are
LinearGreedy (LG), LinearTwoOpt (L2O), and LinearGreedyLinearTwoOpt (LGL2O). Before any of
the three algorithms start searching for the minimum path, a vector of printing points must be created,
which contain all the printing points of the layer. Because of the layer has a very big number of points,
which create a real challenge for algorithms to find the solution in a reasonable time, we create a
vector of lines instead of points. That lines vector will contain far less number of objects that the
algorithm should deal with to find the minimum path, which will decrease the computation time
significantly.
Each line may contain one or more points. The algorithms will use only the starting and ending points
of each line to find the optimal solution. Obviously, if the line contains only one point, the point will
be the starting and ending point at the same time. To create a lines vector from layer’s points with a
reasonable number of lines that will not affect the algorithm from finding the optimal solution and at
the same time decrease the number of objects significantly, the algorithms will follow this procedure:
1- For each point, calculate the number of adjacent points.  See Figure 2.
2- Find a point which has 3 or more adjacent points to be the starting point of a line.
3- Find a point with 2 or less adjacent points and, at the same time, adjacent to the last point
added to the line, and add it to the line.
4- Repeat step 3 until there are no more points that satisfied the criteria in step 3.
5- Find a point that adjacent to the last point added to the line to be the ending point of the line.
6- Go to step 2 until there are no more points left.

5.1. LinearGreedy (LG) Algorithm
After creating the vector of lines from the points of the layer, the algorithm starts searching by
choosing a random line from the lines’ vector as a first line in the optimal path. Next, the algorithm
will calculate the distance from the ending point of the current line to the starting and ending points of
all other lines. The algorithm will choose a line as the next line in the optimal path with the shortest
distance from the ending point of the current line either to the starting or the ending point of the
candidate line. If the ending point was the closest to the current line, the algorithm would reverse the
order of all the points in the line, i.e. the ending point will be the starting point and vice versa. So that,
the ending point of a line will always connect to the starting point of the next line. All the lines will
add only once to the optimal path.
5.2. LinearTwoOpt (L2O) Algorithm
This algorithm uses the lines’ vector that we created from the points of the layer as an initial solution.
After that, the solution is optimized in two stages: Fast Search and Detail Search. In stage one, the
algorithm search for the longest edge between any two lines in the current solution. Next, the
algorithm swaps this edge with all other edges in the current solution to find the lowest cost or
distance of the new path. If the cost of the new path is lower than the current solution, the algorithm
keeps the new path as the new solution. Stage one will be repeated until there is no better solution
founded. After the best new solution has founded, stage two started. In stage two, the algorithm swaps
each edge of the current solution with all other edges to find a path with the lowest cost. If this cost is
lower than the cost of the current solution, this path will be the new solution. Stage two will be
repeated until there is no better solution founded. Figure 4 and Figure 5 shows sample paths before
and after swapping respectively.

8. CONCLUSION AND FUTURE WORK
This work proposes an essential modification to Greedy and Two Opt algorithms for optimizing
toolpath in 3D printing machines. The proposed algorithms are evaluated using actual layers from 3D
models. The big challenge in optimizing 3D printer layers was a large number of points which is a
large computation time-consuming. By using the lines approach, the algorithms will search within
80% - 95% fewer objects. It maintains the ability to find a near optimal solution in very acceptable
time.
In the future work, we plan to improve the algorithms codes and try to find more quick routes to locate
the solution. Moreover, also apply the lines approach on more algorithms like Three Opt and
Christofides algorithms.
