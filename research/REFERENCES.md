# Research references catalog

This file catalogs PDFs under `docs/research/` to track relevance, licensing, and how each paper informs the models and features in this repo.

Guidance
- Prefer linking to DOIs/URLs and summarizing key takeaways in `notes/` over committing additional PDFs.
- Only keep PDFs that are clearly open-access and compatible with public redistribution (e.g., CC BY). When in doubt, keep links + notes only.
- For each paper, capture: features/targets used, preprocessing/renames, where it maps in code (`run_all_training.py` feature lists, `main.py` endpoints/outputs, optimizer configs), and caveats.

Columns
- File: filename in this repo
- OA: open-access (yes/no/unknown)
- License: short label (e.g., CC BY 4.0) or “unknown”

- Link: DOI or canonical URL
- Notes: 1–2 lines on why it matters here
