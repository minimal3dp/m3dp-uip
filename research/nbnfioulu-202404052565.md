ABSTRACT
This work goes through the basic theory of input shaping in context of 3D printers. A
device for measuring the resonance frequencies is designed and manufactured. Input
shaping in Klipper 3d printing firmware is used to test and verify the effectiveness of input
shaping. Printed test pieces and measurements taken during printing were used to
demonstrate that the input shaping reduces vibrations during printing.

Key words: Input shaping, ringing, 3D printing, Klipper.

1 INTRODUCTION
Many of the newly released 3D printers advertise high-speed printing with high accelerations
[1][2]. There are also multiple do-it-yourself 3D printers that have the same goal [3][4]. High
accelerations and speed will cause ringing, sometimes called ghosting, in the printed surfaces.
This ringing is caused by the vibrations happening in the 3D printers frame [5].
Input shaping allows to use high accelerations, because it changes the control signals of the
system, so that the frequency of the movements is not in the resonance frequency area of the
system [6].
Shorter printing times achieved by higher printing speeds and accelerations would allow Fab
Lab Oulu to have more complicated and larger designs to be made in the workshops that they
offer. This would allow the workshop attendees to have greater creativity.
This thesis consists of the designing and manufacturing of a device that allows input shaping
calibration and comparison prints with and without input shaper. The device was designed in a
way that it can be plugged into USB-port, so it is easy to plug in and remove and can be used
in different machines running Klipper. The input shaping device was split into two printed
circuit boards (PCB). One PCB had accelerometer and supporting components and it could be
mounted to the axis that was measured. Second PCB had a microcontroller unit (MCU) on it
and an OLED display and a rotary encoder for controlling the 3D printer.

2 THEORY OF INPUT SHAPING
Input shaping is a technique where motion inputs are altered by input shaper in a way that
reduces the unwanted ringing or vibrations in the system. The idea behind the input shaping
can be explained by using the simplified crane model in Figure 1. If a crane a has load hanging
from its hook, and an impulse is applied to its trolley, the load will start swinging from side to
side. To reduce this swinging, the impulse is divided into two parts. Since the impulse was split,
the first impulse causes less swinging. The second impulse is applied when the load is swinging
the opposite direction, which lessens the swinging of the load even more.[7]


Figure 1. Simplified crane model a) Full impulse is applied at once b) Impulse is split and
second impulse is applied when the load is swinging in opposite direction.

In 3D printing the resonance frequency of the printers X- and Y-axis can be determined and
then used in input shaper to produce a shaped command sent to stepper motor and causing less
ringing than the unshaped command.
In Figure 2 a) input in the systems resonance frequency causes the system to start resonating.
This resonance is dampened after a while because of the systems natural damping. A
convolution of the input and input shaper is calculated to produce the shaped input, the input
shaper part of the convolution can be seen in Figure 2 b). A shaped input causes smaller
amplitude resonance and it dampens faster, as can be seen in Figure 2 c).

3 IMPLEMENTATION


3.1
3D printer used in testing
The device used in the testing was Creality Ender-3 V2 [9] 3D printer, later just Ender-3, with
few modifications. It is a fused filament fabrication (FFF) machine. FFF is an additive
manufacturing method where the nozzle extruding thermoplastic is moved relatively to the part
being produced [10]. Ender-3 is a cartesian machine where the nozzle moves in X- and Z-
directions and the whole printing bed moves in Y-direction.
The original glass bed was changed to magnetic base with a PEI spring steel sheet [11]. The
bowden tube and couplers were changed to Creality Capricorn Bowden tube and couplers [12].
The original heat break was changed to bi-metallic one [13]. The nozzle used in the testing is a
core splitting nozzle similar to Bondtech Core Heating Technology (CHT) nozzles [14]. A 3D
touch, a bed leveling sensor similar to BLtouch [15], and a mounting bracket for it were added.
All the modifications affect the weight of the moving parts which also affects the resonance
frequency of the axis. A MOSFET was added to control the heat break fan so it could be turned
off during the resonance measurements.


3.2
Klipper firmware
Klipper uses a combination of host computer and one or more microcontrollers to control the
hardware of the 3D printer. [16] The host computer can be a general-purpose computer. Usually
it is a single-board computer, in this case it was Raspberry Pi 3 Model B, later just Raspberry
Pi. One of the microcontrollers is usually the original mainboard of the 3D printer or other
standard 3D printer controller board. In this case, mainboard of Ender-3 was used, and another
microcontroller board was designed and manufactured to connect the accelerometer through
USB-interface.


3.3
Hardware design
Two different printed circuit boards (PCB) were designed. One that had ATSAMD21E18 MCU
and one that had the ADXL343 digital accelerometer. Accelerometer board was kept small and
light so it could be easily mounted to toolhead using the bed leveling sensor mount. Dividing
the design to two boards also allowed to add OLED display and rotary encoder with a button to
the MCU PCB. Using two PCBs also allowed them to be single sided PCBs and to be easily
manufactured in Fab Lab Oulu.
In Figure 3 an overview of the hardware can be seen. Raspberry Pi running Klipper host
software was connected to Ender-3 via USB cable. The MCU PCB containing OLED display,
encoder and Serial Peripheral Interface (SPI) connector, was connected to the Raspberry Pi via
USB cable. The accelerometer was connected to the MCU PCB with SPI. It was physically
connected to the Ender-3 toolhead or the bed, depending on which axis resonance was
measured.

4 RESONANCE TEST
Klipper offers two different methods for finding the ringing frequencies of the printer. First
option is a manual method where a test model is printed with specific settings and the ringing
frequency is calculated from the observed and measured printing artifacts [18]. Even more test
models need to be printed to choose input shaper type. The second method uses accelerometer
and enables the use of the auto-tune where the ringing frequency and fitting input shaper is
determined by running an automated test [19]. This thesis focuses on the second method.
Klipper h             “T  T_    N N   ” wh  h generates commands that moves
the axis under test in different frequencies. It generates move commands with varying distance
and acceleration so different frequencies are accomplished. At the same time acceleration data
is logged. [19]

4.1
Resonance test results
Klipper saved the resonance test data into CSV files, a separate file for X- and Y- axis. Graphs
from these files were generated by using the included script in Klipper [20]. Graph for X-axis
resonance can be seen in Figure 7 and for Y-axis in Figure 8. In Figure 7, accelerometer was
attached to the toolhead that moves in the X-direction and as can be seen the power spectral
density of that axis is the dominating resonance, marked in red color. On purple is the
combination of every axis vibration.


Figure 7. X-axis resonances.

This resonance test can also indicate some problems in the printer. If the test had lot of
vibrations in other axis than the one under test or the vibration spectrum was unusually wide, it
could mean that there are some problems with the motion system of the printer. These could be
caused by such things as loose belts or damaged V-wheels.
The narrower the frequency spectrum is the better, this means that a shaper with a shorter
duration can be used. The shorter duration shapers cause less smoothing [18]. Input shapers
implemented in Klipper and their shaper durations are visible in Table 1. The longer shaper
duration input shapers offers more robustness towards modeling errors [21]. If we compare ZV
input shaper with shaper duration of half of the shaper frequency to a 3HUMP_EI input shaper
with a duration of two times the shaper frequency, we can see that ZV has 10% vibration
tolerance in ±5% of the shaper frequency when the 3HUMP_EI offers it in much wider range
from -50% to +55% of the shaper frequency.

5.1
Aurora lamp case
The settings used for the aurora lamp cover focused on not sacrificing the visual quality of the
print while still using higher acceleration and speed. The aurora lamp cover was originally
designed with a wall thickness in a model being 1,2 mm. The total wall thickness of the Fab
Lab logo and wall was 1,7 mm. The outer wall width was set to 0,44 mm and the inner wall to
0,62 mm, this way the Arachne [24] wall generator had enough range to print the wall using
only three walls. The outer and inner wall speed was set to 100 mm/s and the inner and outer
wall acceleration was set to 1000 mm/s2. Rest of the relevant settings are visible in Figure 10.

The aurora lamp case was printed in two orientations, so the differences of each axis could

5.2
75x150mm sanding block
The 75x150mm sanding block was scaled down to 50% to reduce the printing time and to get
tighter tolerances on the screw part. This model had long straight lines, few overhangs and a
threaded part printed in vertical orientation. With this model the acceleration was set just below
the recommended at 4500 mm/s2. The speed was set to 200 mm/s for everything else except
travel, small perimeters and bridges. Travel speed was 500 mm/s, small perimeter speed was
100 mm/s, external bridge speed was 25 mm/s and internal bridge was 38 mm/s. The model
was printed with four perimeters and 20% grid infill to simulate typical engineering part
printing settings.
The sharp corners and overhang on the thumb screw were malformed. This might be able to
be solved with a better part cooling or just by enabling and tuning “slow down for overhangs
setting” in slicer settings. Because the overhang parts curled upwards, 0.2 mm Z hop and a brim
for the thumbscrew was enabled.
Even with the input shaping on there was some visible ringing as can be seen from the Figure

6 DISCUSSION
The resonance frequencies of the system were measured with the developed hardware. Reduced
ringing could be observed from the test prints visually and it was also shown in the collected
data.
The hardware could have some simple upgrades to make it more usable. The MCU PCB
should have some mounting holes so it would be easier to design a case for it. Klipper
documentation calls a second physical SPI interface, if two accelerometers are to be used [19].
ATSAMD21E18 would have support for this, so it could be implemented in the future revision.
There are also some upgrades that could be made to the printer itself. More rigid or lighter
moving parts to increase the speeds and acceleration. The part cooling should be upgraded, and
this could be seen in the overhangs of the 75x150mm sanding block test in Figure 12.

7 SUMMARY
High printing speeds and accelerations cause ringing in the natural frequencies of the printer,
which can be seen in printed objects. Input shaper shapes the input in a way that tries to
minimize the ringing.
The printer used in testing was Creality Ender-3 V2 with some modifications. Klipper
firmware was installed on Raspberry Pi 3 Model B as a 3D printer firmware. Two PCBs were
manufactured, one MCU PCB with ATSAMD21E18 microcontroller and accelerometer PCB
with ADXL343 accelerometer. The MCU PCB was connected to the Raspberry Pi and the
accelerometer could be connected to the axis under test to measure the resonance frequency of
that axis.
The shaper frequency of the X-axis was 87.0 Hz and the recommended shaper was MZV.
For the Y-axis the frequency was 38.4 Hz and the recommended shaper was ZV.
Two different files were printed to demonstrate the effect of input shaping with different
settings. These tests showed that the input shaper improved the printing quality in both cases.
A motion analysis during a print was recorded and this showed that the accelerations were
damped by the input shaper.
There are improvements that could be made to the PCBs and to the printer itself to improve
the usability of the device or gain more speed and acceleration.
