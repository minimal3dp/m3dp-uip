The present work deals with the effects of signiﬁcant parameters of the Fused Deposition Modeling
(FDM) 3D printer on the tensile strength of materials like PETG, ABS and multi-material (60% ABS
+ 40% PETG). The signiﬁcant process parameters have been taken as extrusion temperature, layer height
and material density. ASTM D638-(IV) standard test specimens have been prepared at different process
parameters of the FDM 3D printer to check their tensile strength. UNITEK 94100 Universal testing machine
is used to test the tensile strength of test specimens. Thirty experiments have been performed on the UTM
machine with various materials and their tensile strength has been recorded as output response. The train-
ing between input and output data has been given with ANFIS (Adaptive Neuro-Fuzzy Inference System). It
is observed that maximum tensile strength achieved is 0.0405 kN/mm2 for PETG (material density
1.27 g/cm3) when it is fabricated with 0.1 mm layer height and 225 C extrusion temperature and ANFIS
model is successfully performing for giving output on new input parameters with 2.63 percent error.

1. Introduction
Additive manufacturing or 3D printing become popular in
almost all ﬁelds and ﬁnds its application in food, healthcare, auto-
mobile industries [1]. 3D printing is an advanced manufacturing
technology that fabricates parts by layer addition using the FDM
3D printer as shown in Fig. 1. FDM is one of the most commonly
used 3D printing technology in which parts are build using ther-
moplastic polymer ﬁlaments. FDM fabricates the consolidated
parts having complex shapes and reduce the number of assembly
units [2]. FDM helps in the supply chain by reducing the lead time
along with transportation and storage [3].
3D Printing is a rapid prototyping technology so, production is
additive or generative. Unlike subtractive technology, it does not
need any ﬁnal machining or ﬁnishing process. Fused Deposition
Modeling uses the thermoplastic polymer ﬁlaments to print the
3D parts. The most commonly used ﬁlaments in FDM are PETG,
Nylon, PLA, and ABS. The ISO/ASTM deﬁnes Additive manufactur-
ing, informally known as three-dimensional (3D) printing, as ‘‘pro-
cess of adding the material in layers to form 3D parts, as a resist to
traditional manufacturing and developmental manufacturing tech-
niques”

parameters were optimized and validated using a hybrid statistical
ANFIS tool.

The membership function modiﬁcations are done by fuzzy logic
toolbox and this toolbox is known as ANFIS. ANFIS plays a crucial
role in the formation of the forecasting equation of tensile strength
for various parameters. ANFIS arrests the advantages of both the
fuzzy inference system and artiﬁcial neural network. This combi-
nation of both artiﬁcial neural network and fuzzy logic is the cen-
tral aim of ANFIS [30].
2.5. FIS network formulation
ANFIS tool in MATLAB trains the input variables and output
variables, as identical with the neural network, and utilized for
ﬁnding the input versus output mapping. The membership func-
tion is stated between the input and output variables. These corre-
lated variables can be modiﬁed with the training process. These
variables are ﬁgured out by the gradient vector. The validity of
the input and output values is increased with the help of the gra-
dient vector.
The total of the squared difference between the original and
required output is the error measurement. This error measurement
can be minimized by using a gradient vector by modiﬁcation in
variables in any optimization routine [31]. Both least-square
assessments with backpropagation or backpropagation alone are
used by ANFIS for the evaluation of membership function variables.
2.6. Model authentication:
The generalization capability of results is ensured through the
testing values. Model veriﬁcation is done by checking values set
because after a certain train level, the overﬁtting of values begins.
The model error of the checking values shows decrement when the
fuzzy system trained up to the initial point of over-ﬁtting and
shows increment after a certain period. The working layout of
the ANFIS model is shown in Fig. 4.
The tool contains 5 layers. These are as follows:
Layer 1: The ﬁrst layer is generally known as the Fuzziﬁcation
layer. It has the input values and calculates the membership func-
tion associated with them.
Layer 2: The second layer stands for the rule layer. It is liable for
developing the ﬁring strength for the principles.
Layer 3: The third layer is for the normalization of computed ﬁr-
ing strength. This is done by dividing individual values for the sum
of ﬁring strengths.
Layer 4: The normalized values are the input to this fourth layer
and the defuzziﬁcation values are returned from this layer to be
passed to the last layer.
Layer 5: This ﬁfth layer is for the ﬁnal output [32].

The input/output data is used for training, testing and designing
the ANFIS in MATLAB software. Sugeno-type fuzzy inference sys-
tem is trained by ANFIS and contains one linear output function,
entire rule coverage with no sharing i.e. output member function
is equal to the number of rules and rules have various subsequent
individually. The introductory inference system structure is pro-
duced undoubtedly by it which is according to the training data
and adjusts it even before tuning. The generalization capacity of
the tuned structure is assessed and transport these tuned struc-
tures to the MATLAB.

4. Conclusion
This research work investigates the inﬂuence of FDM process
parameters (layer height, material density and extrusion tempera-
ture) on the mechanical properties of end-use parts. The analysis
shows that the tensile strength is affected by extrusion tempera-
ture and layer height identically. Tensile strength is more inﬂu-
enced by extrusion temperature rather than layer height, higher
extrusion temperature favors the high tensile strength of the test
pieces up-to a certain limit. The maximum tensile strength
0.040 kN/mm2 is observed in PETG material at an extrusion tem-
perature of 225 C with a layer height of 0.1 mm. The statistical
tool ANFIS is utilized to validate and prediction for tensile strength
of test specimens. ANFIS model testing trail shows that the PETG
ﬁlaments show maximum tensile strength at 225 C extrusion
temperature and 0.1 mm layer height. The created ANFIS model
shows a minimal error percentage of 2.63% which validates the
experimental results.
