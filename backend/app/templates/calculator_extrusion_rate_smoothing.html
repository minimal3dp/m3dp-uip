📖 What is ERS?

Extrusion Rate Smoothing is an experimental OrcaSlicer feature that smooths extrusion rate changes during acceleration/deceleration, reducing pressure fluctuations in the nozzle.

Formula: ERS Max = Acceleration × Line Width × Layer Height

  • Start with 60% of max for conservative tuning
  • Use 80% of max for printers with good flow consistency
  • Higher values = smoother flow but may reduce detail
  • Lower values = preserve detail but more flow fluctuation

Note: Requires OrcaSlicer 2.0+ and may not be compatible with all printers.
