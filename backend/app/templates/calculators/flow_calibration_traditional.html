Flow Calibration (Traditional)

Calculate optimal flow rate by measuring wall thickness of a printed hollow cube.

Measurements

Slicer Settings

mm

Multiplier set in slicer during test print (usually 1.0 or 0.95)

Cube Wall Thickness

Measure center of each wall near the top.

Before You Start

  1. Print a standard hollow cube (40x40x40mm is common).
  2. Slicer Settings:
    • Infill: 0%
    • Top Layers: 0
    • Perimeters: 2 (recommended)
  3. Ensure extrusion multiplier is set to 1.0 (or note it).
  4. Measure the thickness of each of the 4 walls near the top center.
Hardware Required You will need accurate digital calipers for this test. Recommended: Digital Calipers (Affiliate) →
